# Аерогриль — сайт рецептів і меню

Сайт рецептів і готових меню для аерогрилю (air fryer). Мова сайту й спілкування — українська.

## Три ролі: кожне рішення перевіряй з трьох боків
1. **Веб-дизайнер.** Стильно, чисто, «апетитно». Спочатку мобільна версія. Велике фото страви, багато повітря, 1–2 шрифти, обмежена палітра (теплі відтінки). Жодних шаблонних «AI-градієнтів».
2. **Кулінар.** Рецепт має бути робочим для аерогрилю: температура (°C), час, чи потрібен розігрів, коли струсити/перевернути, скільки влазить у кошик, ознаки готовності. Інгредієнти в грамах і штуках, у порядку використання.
3. **Користувач.** Людина стоїть біля плити з брудними руками. Потрібні: швидкий пошук і фільтри (час, категорія, складність), крупний текст кроків, кнопка «режим готування» (екран не гасне), чекбокси інгредієнтів, перерахунок порцій, друк і список покупок.

## Технічні правила
- Стек: статичний HTML + CSS + чистий JS (Node.js на цьому Mac не встановлений). Фреймворк — тільки якщо погодимо окремо.
- Застосунок для будь-якого аерогрилю (еталон для перевірки — Tefal Easy Fry Mega EY855D10, 7,5 л). Головне — правильні °C і час: беремо консенсус відгуків власників, а не офіційні застосунки виробників. Повне ТЗ — `PROMPT.md`.
- Рецепти зберігаються як дані (`data/recipes.js`, `window.RECIPES`), а не вписуються в HTML вручну. Одна картка й одна сторінка рецепта — шаблон для всіх.
- Поля рецепта: `id, title, cat, temp, time[min,max], preheat, flip, load, done, serv, whole?, ing[], steps[], why, tags[]` (`whole: "пояснення"` — ціла тушка або одна форма, порції не перераховуються).
- Кожна сторінка рецепта має розмітку Schema.org `Recipe` (JSON-LD) для Google.
- CSS-змінні для кольорів, шрифтів і відступів в одному місці (`css/tokens.css`).
- Доступність: контраст ≥ 4.5:1, alt у фото, кнопки не менші за 44px.
- Перевіряй результат у вбудованому браузері (мобільна й десктопна ширина), а не на словах.

## Публікація
- Сайт: https://sergiushp.github.io/aerogril/ (GitHub Pages з гілки `main`, репозиторій SergiusHp/aerogril).
- Оновити сайт = commit + `git push`; Pages перезбирається сам за 1–2 хв. GitHub CLI: `~/.local/bin/gh`.
- Після змін у css/js/data підніми номер `?v=` у `index.html` (усі 6 посилань), інакше телефони показують стару версію з кешу.
- Локальний перегляд: python-сервер не має доступу до Робочого столу, тому копіюємо сайт у scratchpad (rsync) і запускаємо `.claude/launch.json` звідти.

## Економія токенів
- Відповідай коротко, по суті, без переказу того, що вже зроблено.
- Не перечитуй файли, які щойно читав або редагував. Для змін — Edit, а не повне переписування файлу.
- Читай лише потрібну частину великого файлу (offset/limit, grep).
- Незалежні дії виконуй паралельно в одному кроці.
- Не створюй зайвих файлів, README і коментарів «для краси».
- Не питай дозволу на очевидне — пропонуй одне найкраще рішення, а не список варіантів.
- Субагентів не запускай без потреби.
